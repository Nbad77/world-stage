COMPLEX OFFER SYSTEM
================================================================================

Every turn presents 5 options:

A) USA OFFER
   - Turn 1-2: Basic partnership (+15 relations)
   - Turn 3-4: Sanction Arabia (+20 USA, -30 Arabia)
   - Turn 5+: Military alliance (stability, USA+, Arabia-)
   - If sanctioned: Negotiate removal ($5B cost)
   - If relations > 70: Form alliance

B) ARABIA OFFER
   - Basic: Oil deal (+$3B, oil -$5)
   - Enhanced (turn 4+): Better deal (+$5B, oil -$10)
   - Premium (relations > 70): Exclusive (+$8B, oil -$15)
   - If embargo: Apologize ($4B cost)

C) EU OFFER
   - Default: Align with values (+stability, +relations)
   - If both USA/Arabia hostile: Mediation
   - If stability < 45: Emergency aid (+$4B, +15 stability)
   - If relations > 65: Integration process

D) DPRG OFFER
   - Default: Acknowledge (+8 DPRG, -5 USA/EU)
   - If budget < 20: Emergency loan (+$10B)
   - If stability < 35: Surveillance tech
   - If USA hostile: Weapons deal
   - If relations > 60: Military pact

E) DO NOTHING
   - All relations -5, stability -2%

GAME MECHANICS
================================================================================

CORE RESOURCES:
  Budget: $50B starting (loss at ≤ $0)
  Stability: 70% starting (loss at ≤ 0%)
  Oil Price: $75/barrel starting (min $20)

CRISIS SYSTEMS:
  USA Sanctions (relations < 25): -$2B per turn
  Arabia Embargo (relations < 25): +$4 oil price per turn

TURN STRUCTURE:
  1. Status display
  2. All 4 NPCs speak
  3. Player chooses ONE option (A-E)
  4. Immediate consequences
  5. End-of-turn effects
  6. Check game over
  7. Advance turn (max 10)

WIN/LOSS:
  Victory: Survive 10 turns
  Defeat: Bankruptcy (budget ≤ $0)
  Defeat: Collapse (stability ≤ 0%)
