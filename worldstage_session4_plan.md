## SESSION 4B — ELECTION MECHANIC
**Priority: Highest — central to game identity**

### What it is
An election fires once per game at a scripted turn (turn 4 or 5). Player chooses how to run it on a spectrum from fair to canceled. The choice affects regime type more than any other single decision.

### Mechanical spec

**Election trigger**
- Fires automatically at turn 4 or 5 as a special event
- Pre-warning appears turn 3: "Elections scheduled next turn"
- Cannot be skipped — player must choose one of four options

**Four election options (always shown, consequences differ by game state)**

Option A — Hold fair election
  - Available always
  - Requires: approval 65+ to succeed cleanly
  - If approval 65+: EU +8, USA +5, stability +5%, approval +3%
  - If approval 50-64: EU +3, USA +3, stability -3% (squeaker win, West suspicious)
  - If approval below 50: regime collapse risk — stability -15%, protests fire
  - Regime label: stays current or shifts toward Managed Democracy

Option B — Finger on the scale
  - Available always
  - Cost: -$2B personal (buying votes/media)
  - Outcome: approval treated as +15% for election purposes only
  - EU -5 (suspicious), USA -3 (suspicious), Arabia neutral, DPRG neutral
  - Stability +3% (controlled outcome)
  - Regime label: shifts right one step (Managed Democracy → Soft Authoritarianism)
  - Heat: +10%

Option C — Cancel election / state of emergency
  - Available always
  - Outcome: stability +10% short term, approval -15%, EU -15, USA -10
  - Regime label: hard right shift (jumps two steps toward Totalitarian)
  - Protests fire next turn (mandatory brigade response required)
  - Ji-won approves: DPRG +5
  - Unlocks authoritarian domestic actions immediately
  - Heat: +20%

Option D — International observers (transparent election)
  - Available only if approval 60+ and no suppression actions taken
  - Cost: -$1B (logistics)
  - Outcome: EU +15, USA +10, credibility bonus lasts 3 turns
  - Stability -2% (genuine uncertainty during process)
  - Regime label: Managed Democracy locked for 3 turns (cannot shift right)
  - Marsha offers: post-election EU partnership deal unlocked
  - This is the rarest path — sets up Democratic Transition ending


**No passive decay** — Tech is permanent once acquired

### Intelligence Budget resource

**What it does**
- Separate pool from personal wealth
- Funded from national budget (player allocates each turn)
- Covers: apparatus maintenance, operation costs, tier upgrades

**Allocation mechanic**
- Each turn, before skim decision: "Allocate intelligence budget this turn"
- Options: $0 (apparatus degrades), $1B (maintenance), $2B (active operations), $3B (expansion)
- At $0 for 2 consecutive turns: apparatus tier drops one level
- Core tradeoff: fund apparatus OR fund stability/GDP

**Why this matters**
- Removes intelligence from personal wealth — currently players skip intel because it costs personal funds they're skimming
- Creates genuine resource competition: budget → stability vs. budget → intel
- Apparatus becomes a long-term investment with real maintenance cost

## DESIGN NOTES

**Election is the most important feature in this session:**
The election mechanic is what makes the regime progression system feel intentional rather than accidental. Right now players slide toward Totalitarian through skim decisions without ever making an explicit authoritarian choice. The election forces a named moment — "I am choosing to cancel democracy" — which creates the moral weight the game is supposed to have.

**Domestic actions create the dependency loop:**
State Media Takeover → approval floor rises → less need for EU alignment → more skimming → Judicial Capture → corruption risk gone → more skimming. Each action solves a problem while deepening the structural trap. This is the core design principle in action.

**Intel Budget changes the resource game:**
Currently intel is a luxury because it costs personal wealth players are trying to accumulate. Moving it to national budget makes intel a real strategic choice — you're trading stability/GDP for intelligence capability. This also sets up the Session 6 permanent intelligence infrastructure properly.
